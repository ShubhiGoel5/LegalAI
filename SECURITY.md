# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. Use GitHub private vulnerability reporting: https://github.com/ShubhiGoel5/LegalAI/security/advisories/new
2. **Title:** `[SECURITY] LegalAI — <brief description>`

Do **not** open a public GitHub issue for security vulnerabilities.

We will respond within 48 hours.

## Important Notes
- Never commit API keys, passwords, or tokens
- All database credentials must use environment variables
- AI outputs must include disclaimer: "This is not legal advice. Please consult a qualified advocate."
